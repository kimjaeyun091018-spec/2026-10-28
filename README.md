## 숲공부 프로토타입 (`prototype/`)

묘목 한 칸에서 시작해, 공부한 시간과 찾아온 손님으로 레벨을 올리며 섬을 넓혀가는 공부 타이머의 맛보기 버전입니다.

- 공중에 뜬 블록 섬을 45도 각도에서 내려다보는 화면. 블록 무늬는 16×16 픽셀 텍스처를 코드로 생성 (이미지 파일 없음)
- 시작은 어미나무 묘목 1칸. 공부할수록 새싹 → 덤불 → 어린나무 → 큰나무로 자람
- 손님(실제 생물)이 처음 찾아올 때마다 경험치 +10, 공부 1분마다 +1. 레벨이 오르면 십자 모양으로 땅이 한 바퀴씩 열림 (Lv 5까지, 최대 41칸)
- 열린 빈 땅을 눌러 지형을 고름: 초원, 꽃밭, 참나무 숲, 자작나무 숲, 벚나무 숲, 침엽수림, 강, 습지, 돌산
- 재화 3가지
  - 씨앗: 공부 1분마다 1
  - 물방울: 5분 넘게 공부하고 마치면 2
  - 돌: 25분 넘게 한 번에 공부하고 마치면 3
- 손님 18종: 무당벌레, 참새, 배추흰나비, 꿀벌, 멧토끼, 다람쥐, 박새, 오색딱따구리, 동박새, 여우, 노루, 피라미, 비버, 참개구리, 반딧불이, 왜가리, 산양, 검독수리. 지형 조합으로 찾아옴 (예: 참나무·자작나무 숲 옆에 강이 있으면 비버)
- 공부 중 화면을 벗어나면 그 세션은 없던 일이 됨 (재화·손님·땅 모두 세션 시작 전으로)
- 시연 모드: 1초를 1분으로 계산
- 기록은 브라우저 localStorage에만 저장

### 실행

`prototype/index.html`을 브라우저로 열면 됩니다. 별도 빌드나 설치는 없습니다.
