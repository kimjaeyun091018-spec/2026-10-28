# 민둥산 숲 이야기

공중에 뜬 민둥산 디오라마를 45도 위에서 바라보는 **힐링 방치형 생태계**.
플레이어는 아무것도 심지 않아요. 바람과 강물이 생명을 실어 오고, 숲이 생기면 동물이 스스로 찾아와요. 그저 지켜보면서 도감을 채우면 돼요.
`index.html` 한 파일로 PC·휴대폰 브라우저에서 실행되고(3D는 three.js r128), 진행은 브라우저에 자동 저장돼요.

## 보는 법
- 끌어서 둘러보기, 휠·두 손가락·＋− 로 확대, ⟲ ⟳ 로 45도씩 돌리기, ◎ 천천히 저절로 돌며 둘러보기
- 땅·나무·동물을 누르면 지금 상태가 나와요 (해발 고도, 수분, 흙 기름짐, 나무 높이·나이·병, 동물이 하는 일)
- 시간: 멈춤 / 1배 / 4배 / 16배. 1배에서 한 계절은 2분, 1년은 8분
- 창을 닫아도 시간이 흘러요. 돌아오면 그사이 일어난 일을 알려 줘요 (최대 2년치)

## 저절로 일어나는 일
- **개척**: 바람이 이끼 포자를 바위에 내려놓고, 이끼가 바위를 흙으로 바꿔요. 강물과 바람이 풀씨를 실어 오고, 흙이 생기면 자작나무 씨앗이, 높은 곳엔 소나무 씨앗이, 물가엔 버드나무 씨앗이 날아와요.
- **번식**: 나무는 다 자라면 바람에 씨앗을 날려요. 새는 씨앗을 멀리 옮기고, 다람쥐는 가을에 도토리를 묻었다가 잊어버려 숲을 넓혀요.
- **동물이 찾아옴**: 나무가 자라면 새가, 풀밭이 넓어지면 멧토끼가, 숲과 풀밭이 함께 있으면 노루가, 토끼가 많아지면 여우가, 강가 나무가 우거지면 비버가, 참나무·소나무 숲엔 다람쥐가 와요. 사라진 동물도 살 만해지면 다시 와요.
- **먹고 먹히기**: 토끼는 풀과 새싹, 노루는 풀과 어린나무, 여우는 토끼를 먹어요. 새는 병든 나무의 벌레를 쪼아 병이 번지는 걸 막아요. 비버는 물가 나무로 댐을 쌓아 연못을 만들어요.
- **병충해 (시한부)**: 병든 나무는 정해진 날 뒤에 쓰러지고, 그 흙엔 1년 동안 같은 나무가 못 자라요. 같은 나무끼리 빽빽할수록 잘 생기고 잘 번져요.
- **계절**: 봄 새잎과 꽃, 여름 짙은 초록과 벌레, 가을 단풍과 낙엽, 겨울 눈과 언 강. 겨울에 떨어진 씨앗은 땅속에서 잠들었다가 봄에 싹터요.

## 자연재해 (저절로 일어나요)
| 재해 | 언제 | 무슨 일이 |
|---|---|---|
| 산불 | 메마른 여름·가을, 숲이 클 때 | 번개로 시작해 바람을 타고 번지고, 비가 오면 꺼져요. 탄 자리는 재가 거름이 되어 풀이 먼저 돋아요. |
| 홍수 | 봄·여름 큰비 | 강가가 잠기고 어린나무가 쓸려 가요. 물이 빠지면 고운 흙이 남아요. **물길이 바뀌기도 해요.** |
| 지진 | 아무 때나 | 가파른 비탈이 무너져 산사태가 나고 바위가 갈라져요. **물길이 바뀌기도 해요.** |
| 화산 폭발 | 3년째부터, 몇 해에 한 번 | 산꼭대기에서 용암이 흘러내리고 화산재가 내려요. 용암은 식어 검은 바위가 되고, 화산재는 몇 해 뒤 가장 기름진 흙이 돼요. |

물길이 바뀌면 옛 강줄기는 습지로 남았다가 천천히 말라 기름진 **옛 물길**이 돼요.

## 도감
- **생물도감 21종**: 지의류, 들풀, 들꽃, 버섯, 자작나무, 소나무, 참나무, 버드나무, 나비, 피라미, 개구리, 멧토끼, 다람쥐, 노루, 여우, 비버, 박새, 곤줄박이, 딱새, 꾀꼬리, 오색딱따구리
- **지형도감 17곳**: 민둥 바위, 강, 이끼 바위, 맨흙, 풀밭, 꽃밭, 숲, 깊은 숲, 비버 연못, 습지, 옛 물길, 범람원, 불탄 땅, 화산재 땅, 용암 바위, 산사태 자국, 눈 덮인 봉우리

처음 나타나면 저절로 기록되고, 언제 발견했는지와 지금 몇이 사는지 보여 줘요.

## 진화 (자연 진화 계통도)
고르는 게 아니라, 생물이 겪은 일이 쌓이면 저절로 열려요. 계통도에서 무엇을 겪어야 하는지와 지금까지 쌓인 정도를 볼 수 있어요.

| 생물 | 진화 | 무엇을 겪으면 |
|---|---|---|
| 지의류 | 바위 녹이는 산 (바위를 1.6배 빨리 흙으로) | 바위를 오래 덮을수록 |
| 들풀 | 깊은 뿌리 (가뭄에 덜 시듦) · 재에서 다시 (불탄 땅에서 2배 빨리) | 가뭄에 시들수록 · 불에 탈수록 |
| 나무 4종 각각 | 병 저항 → 튼튼한 수액 → 병을 이기는 나무 (셋 중 하나는 병을 스스로 이겨냄) | 병으로 쓰러질수록 |
| 나무 4종 각각 | 가뭄 적응 · 두꺼운 껍질 (산불에서 절반은 살아남음) | 말라 죽을수록 · 불에 탈수록 |
| 멧토끼 | 빠른 뒷다리 · 굴 파기 | 여우에게 잡힐수록 · 겨울에 굶을수록 |
| 여우 | 예민한 코 | 굶을수록 |
| 노루 | 겨울털 | 겨울에 굶을수록 |
| 새 | 단단한 부리 (병든 나무를 더 오래 지킴) | 벌레를 쪼을수록 |
| 비버 | 큰 앞니 | 댐을 쌓을수록 |
| 다람쥐 | 잊어버리는 버릇 (묻은 씨앗이 더 많이 숲이 됨) | 씨앗을 묻을수록 |

병에 많이 쓰러진 나무일수록 병에 강해지기 때문에, 시간이 지나면 숲이 스스로 병을 이겨내기 시작해요.
