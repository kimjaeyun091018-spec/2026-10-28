## 숲공부 프로토타입 (`prototype/`)

공부한 시간만큼 지형이 자라고, 조건이 맞으면 동물이 나타나는 생태계 공부 타이머의 맛보기 버전입니다.

- 지형 3개: 강, 숲, 초원 (지형마다 공부 시간이 따로 쌓임)
- 생물 연쇄: 예) 강 → 갈대 → 버드나무 → 비버 → 비버 댐(연못 생성) → 개구리 → 왜가리
- 공부 중 화면을 벗어나면 그 세션 시간은 기록되지 않고, 그동안 찾아온 생물도 떠남
- 시연 모드: 1초를 1분으로 계산해서 빠르게 성장을 확인
- 기록은 브라우저 localStorage에만 저장

### 실행

`prototype/index.html`을 브라우저로 열면 됩니다. 별도 빌드나 설치는 없습니다.
