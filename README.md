# 종이 접는 용사 (가제)

캐릭터도 적도 세계도 **종이**인 2D 액션 게임. 모험하며 **종이접기 도안**을 얻고, 그 도안의 점선을 따라 직접 종이를 접어 무기·도구를 만든다. **점선에 얼마나 정확히 맞춰 접었는지에 따라 도구의 성능이 달라진다.**

> 이 브랜치(`orgami`)에는 이 게임만 둔다. 숲공부 프로토타입은 `main`, 식물 액션(「뿌리 아래로」)은 `plant-world-action`에 있다.

## 출발점

`plant-world-action`의 "3D 배경 + 2D 캐릭터"에서 영감을 받음. 2D로 간다면 캐릭터가 아예 종이라면 어떨까 → 납작한 것이 자연스러운 세계, 종이를 겹친 디오라마 같은 배경.

## 핵심 규칙

1. 도안을 얻는다 (세계 곳곳의 책상에 놓여 있음)
2. 종이 위에 점선이 보이고, 플레이어가 종이를 잡아 끌어서 접는다
3. 접는 선이 점선과 얼마나 겹치는지로 단계마다 정확도가 매겨지고, 평균으로 도구 등급(S~D)과 성능이 정해진다
4. 비뚤게 접으면 다음 점선도 비뚤어진 종이를 따라 옮겨 간다 (실제 종이접기처럼 오차가 쌓임)
5. 만든 도구는 게임 안에서 **실제로 접은 모양 그대로** 보인다 — 비뚤게 접은 칼은 비뚤어 보임

## 첫 프로토타입 (`index.html`)

브라우저로 `index.html`을 열면 바로 플레이 (설치·빌드 없음). 마우스 + 키보드.

### 접기 화면
- 커팅 매트 위 정사각형 종이. 실제 종이접기처럼 색면을 아래로 두고 시작해서, 접어 넘긴 면에 색이 보임
- **반짝이는 점을 잡고 화살표 끝으로 끌어 놓기**: 잡은 점이 놓은 곳에 오도록 접힘 (접는 선 = 두 점의 수직이등분선). 끄는 동안 접힌 결과와 내 접는 선, 정확도가 바로 보임
- 정확도: 점선 양 끝 두 점에서 내 접는 선까지의 평균 거리(종이 한 변 = 200). 0이면 100%, 14 이상이면 0%. 34보다 멀거나 반대쪽을 잡으면 접히지 않음
- 단계 정확도 평균 → 등급 S(93%+) · A(82%+) · B(68%+) · C(50%+) · D
- R: 새 종이로 처음부터, Esc: 나중에. 이미 만든 도구도 책상에서 E로 다시 접어 바꿀 수 있음

### 도안 4종

| 도안 | 단계 | 역할 | 정확도가 바꾸는 것 |
|---|---|---|---|
| 종이 칼 | 5 | 근접 베기 (J·왼쪽 클릭) | 공격력 1~3, 사거리 22~52px |
| 종이비행기 | 5 | 공중에서 점프 누르고 있으면 활공 | 낙하 속도 150→30, 이동 ×1.0~1.35 |
| 종이 표창 | 4 | 마우스 쪽으로 던지기 | 위력, 사거리 190~520px, 흔들림 ±14°→0° |
| 종이 방패 | 4 | K·오른쪽 클릭 누르고 있으면 앞쪽 막기 | 막기 횟수 2~8번 (다 쓰면 찢어짐 → 다시 접기) |

### 스테이지 (한 판, 약 4000px)
- 칼 책상 → 구김이(구겨진 종이 뭉치) → 비행기 책상 → **잉크 웅덩이 300px** (활공 없이는 못 건넘. 끝에서 뛰면 비행기 정확도 약 45% 이상이어야 건넘)
- 표창 책상 → 잉크 웅덩이(220px) 건너편 **병풍 문** 앞면 높은 곳의 과녁을 표창으로 맞히면, 병풍이 쓰러져 다리가 됨 (웅덩이 건너에서 던져야 해서 표창 정확도 약 40% 아래면 사거리가 모자람)
- 방패 책상 → **잉크병** 두 개가 잉크를 3연발로 쏨 → 황금 종이학에 닿으면 클리어 (도구별 등급 결과 화면)
- 체력 5 (종이 하트). 잉크에 빠지면 -1, 책상이 체크포인트

### 그림
- 캐릭터·적·도구·땅은 캔버스 코드로 그림 (접은 종이처럼 면을 밝게/어둡게 나눔). 주인공이 돌아설 때 종이처럼 얇아지며 흰 뒷면이 잠깐 보임
- 먼 배경 `assets/bg-forest.jpg`: Kaggle 무료 GPU에서 SDXL base로 생성(`tools/concept-gen/gen_kaggle.py`·`push.py`), 1085×620으로 줄이고 채도를 살짝 낮춤. 그 앞에 캔버스로 그린 종이 언덕·나무 한 겹
- `assets/concept/`: 같은 실행에서 나온 시안 전부 (숲 배경 4, 마을 배경 4, 종이 주인공 4)와 프롬프트 `prompts.json`

## 아직 정할 것

- [ ] 장르 뼈대: 지금은 옆에서 보는 액션 한 판. 탐험형(메트로배니아) / 스테이지형 / 로그라이크 중 어느 쪽으로
- [ ] 종이 재료: 종이 장수 제한, 종이 종류(두꺼운 종이 = 튼튼, 얇은 종이 = 가벼움, 색종이 = 속성) 넣을지
- [ ] 접기 조작의 난이도: 지금은 끄는 동안 정확도가 보임(쉬움). 숨기거나, 시간 제한·흔들림을 넣을지
- [ ] 산접기(뒤로 접기)·뒤집기·펼쳐 누르기 같은 더 복잡한 접기를 넣을지 (지금은 골접기만)
- [ ] 도구 내구도: 베거나 막을수록 구겨져 성능이 떨어지게 할지
- [ ] 세계관: 종이 세계가 왜 위험해졌는지 (잉크? 가위? 물?)
- [ ] 휴대폰 조작 (접기는 터치로 되지만 스테이지는 키보드 전용)
