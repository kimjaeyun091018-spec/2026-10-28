# 주사위 던전 (주사위 × 카드 로그라이크)

도트 그래픽으로 만드는 턴제 로그라이크. 요트 다이스의 주사위 족보와 포커의 카드 족보를 한 전투에 섞었다.

> 이 브랜치(`dice-card-roguelike`)에는 이 게임만 둔다. 숲공부 프로토타입은 `main` 브랜치에 있다.

## 핵심 시스템 (요트 + 포커)

- 매 턴 **주사위 5개**를 굴리고 **카드 5장**을 뽑는다.
- 요트처럼 남길 주사위를 고정하고 **다시 굴림 2번**. 확정하면 주사위를 카드에 넣는다.
- 카드는 **속성(불·물·풀·번개) + 숫자**. 숫자 1~6은 같은 눈 1개, 7~12는 **두 주사위의 합**으로 발동.
- 발동 버튼을 누르면 채운 카드 효과와 족보 보너스가 한꺼번에 적용된다.
  - 불: 피해 / 물: 방어 / 풀: 독 / 번개: 관통 피해(방어 무시)

### 주사위 족보 (요트, 주사위 5개 전체)

| 족보 | 조건 | 효과 |
|---|---|---|
| 요트 | 5개 같은 눈 | 모든 피해 2배 |
| 포카드 | 같은 눈 4개 | 피해 +10 |
| 풀하우스 | 3개 + 2개 | 방어 +10 |
| 라지 스트레이트 | 5개 연속 | 피해 +8 |
| 스몰 스트레이트 | 4개 연속 | 피해 +4 |

### 카드 족보 (포커, 발동한 카드끼리)

| 족보 | 조건 | 효과 |
|---|---|---|
| 원페어 / 투페어 | 같은 숫자 2장 | 피해 +3 / +6 |
| 트리플 | 같은 숫자 3장 | 관통 피해 +6 |
| 스트레이트 | 숫자 3장 연속 | 다음 턴 다시 굴림 +1 |
| 플러시 | 같은 속성 3장 | 불 피해 +8 · 물 회복 8 · 풀 독 +5 · 번개 관통 +6 |

## 진행

- 기사 HP 50, 지하 5층 (슬라임·박쥐 → 독버섯 → 해골 병사 → 돌 골렘 → 주사위 마왕)
- 적은 다음 행동(공격·방어·독·저주)을 미리 보여 줌. 마왕의 저주를 받으면 다음 턴 주사위 4개
- 층을 깰 때마다 카드 3장 중 1장 선택(넘어가기 가능), 체력 10 회복
- 반쯤 채운 카드를 누르면 넣었던 주사위가 돌아옴

## 앞으로 넣을 것

- 주사위 면 강화 (1→6, 불꽃 면 등), 유물(패시브 효과)
- 갈림길 맵: 전투 / 상점 / 휴식 / 보스

## 그래픽

- 16×16 도트, 캔버스 코드로 그림 (이미지 파일 없음)
