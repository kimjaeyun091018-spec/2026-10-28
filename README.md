# 2026-10-28

## 숲공부 프로토타입 (`prototype/`)

묘목 한 칸에서 시작해, 공부한 시간과 찾아온 손님으로 레벨을 올리며 끝없이 넓어지는 섬을 키우는 공부 타이머의 맛보기 버전입니다.

### 화면
- **섬이 화면 전체를 채우는 배경**이고, 그 위에는 버튼과 꼭 필요한 표시만 떠 있음: 왼쪽 위 레벨·경험치 막대와 하늘(시간·날씨), 오른쪽 위 ☰ 메뉴와 ⟲ ⟳ ⌂ 버튼, 아래쪽 타이머와 공부 시작 버튼
- 구름 위에 뜬 섬을 three.js(r128) 3D로 그림. 「펭귄의 섬」처럼 깔끔하고 부드러운 화면을 참고해, 평평한 땅을 내려다보고 해·달 방향에서 부드러운 그림자가 짐
- **낮과 밤**: 16분마다 새벽 → 낮 → 해 질 녘 → 밤이 한 바퀴 돎(메뉴에서 실제 시각에 맞출 수 있음). 해와 달이 하늘을 지나가고, 밤에는 별이 뜨고 빛나는 것들이 더 밝아짐
- **날씨**: 맑음·흐림·비·눈·안개가 몇 분마다 바뀜. 빗방울과 눈송이는 작은 큐브
- **밤의 반딧불이**: 밤이 되면 풀숲과 숲 위로 큐브 모양 반딧불이가 깜빡이며 떠다님 (비나 눈이 오면 숨음)
- 나무와 동물은 큐브(복셀)로 쌓은 모양. 나무는 작은 잎 블록이 모인 수관이 바람에 흔들리고, 동물은 모서리가 둥근 큐브로 만든 장난감 같은 모양
- 끌어서 섬 위를 이동하고, 두 손가락을 비틀거나 오른쪽 버튼(또는 Ctrl·Shift)으로 끌면 회전, 두 손가락이나 휠로 확대. 앞쪽으로 끌어당기면 카메라 가까운 땅이 녹듯이 사라져서 뒤쪽이 보임
- 섬 가장자리: 숲과 풀밭은 흙벽이 안 보일 만큼 빽빽한 덩굴, **사막·바닷가는 모래, 설원은 눈, 물은 폭포가 실제로 흘러내리고** 큐브 알갱이가 떨어짐
- 계정(구글 로그인), 섬 정보, 손님 도감, 설정(시연 모드, 실제 시각, 처음부터), 도움말은 ☰ 메뉴 안에 있음

### 섬 고르기
- 처음 열면 키울 섬을 고름: **숲 섬**(꽃밭에서 시작해 숲·강·습지·벚나무·대나무숲, 가장자리엔 침엽수림·돌산), **눈 섬**(설원과 얼음 호수 → 침엽수림·자작나무 숲·돌산), **사막 섬**(모래 언덕과 오아시스 → 바닷가), **바다 섬**(모래사장과 파도 → 강·습지·초원)
- 섬마다 레벨, 공부 시간, 어미나무, 땅이 따로 자라고, 손님 도감과 설정은 함께 씀. 섬마다 사는 손님이 달라서 도감을 다 채우려면 여러 섬을 키워야 함
- 왼쪽 위 섬 이름(레벨 칩)이나 메뉴 → "다른 섬으로"에서 바꿈 (공부 중엔 못 바꿈). "이 섬 처음부터"는 지금 섬만 지움
- 예전 저장은 숲 섬으로 옮겨짐

### 규칙
- 경험치: 공부 1분마다 1, 처음 찾아온 손님마다 10. 레벨에 필요한 경험치는 15, 50, 110, 200, 325… 로 끝없이 늘어남
- 레벨이 오르면 섬이 **마름모 모양으로 한 바퀴씩** 넓어짐 (끝없음, 새 땅 4×(레벨−1)칸)
- **지형은 넓은 구역(약 7×7칸, 경계는 들쭉날쭉) 단위로 하나씩** 저절로 정해짐. 13종: 꽃밭, 초원, 참나무 숲, 자작나무 숲, 벚나무 숲, 침엽수림, 강, 습지, 돌산, 사막, 설원, 대나무숲, 바닷가. 구역 사이는 높이와 색이 부드럽게 섞임
- **같은 지형끼리 크게 모이고, 기후가 안 맞는 지형은 붙지 않음**: 섬마다 다른 기후 지도(설원 → 추운 숲·돌산 → 온대 → 바닷가 → 사막)가 아주 천천히 변해서, 이웃 구역은 기후가 한 단계 넘게 차이 나지 않음 (설원 옆에 사막이 오는 일은 없음). 새 구역은 대개 이웃 지형을 이어받고, 새 지형이 나올 땐 아직 못 만난 손님이 사는 지형이 더 잘 나옴. 그래서 사막·설원 같은 끝 기후는 섬이 꽤 넓어져야 나타남
- 구역마다 손님이 **한두 마리** 삶 (구역이 8칸 넘게 열리면 찾아옴). 손님 25종

- 시연 모드: 1초를 1분으로 계산 (메뉴 → 설정)

### 구글 로그인 (Firebase)

지금은 소울나이트식 게임(`20260625` 저장소, `feature/roguelike-shooter-pc`)과 같은 Firebase 프로젝트 `dongeon-shooter`를 함께 써요. 나중에 이 게임 전용 프로젝트로 바꾸려면 `prototype/index.html`의 `FIREBASE` 값만 바꾸면 돼요.

저장 위치는 `forest/{uid}` = `{ data: "섬 기록 JSON", t: 마지막 저장 시각 }` 이에요. 소울나이트의 `saves/{uid}`와 섞이지 않게 따로 뒀어요.

Firebase 콘솔에서 처음 한 번:
1. **Realtime Database → 규칙**의 `"rules"` 안에 아래 항목을 추가하고 게시 (기존 `users`, `saves`, `guild…` 규칙은 그대로)
   ```json
   "forest": {
     "$uid": { ".read": "auth != null && auth.uid === $uid", ".write": "auth != null && auth.uid === $uid" }
   },
   ```
2. **Authentication → 설정 → 승인된 도메인**에 게임을 여는 주소가 있는지 확인 (GitHub Pages면 `kimjaeyun091018-spec.github.io`는 이미 들어 있음)

규칙을 추가하기 전에도 게임은 그대로 되고, 계정 칸에 "권한이 없어요"라고만 나와요. 파일을 컴퓨터에서 바로 열면(`file://`) 구글 로그인이 안 되니, GitHub Pages나 `npx serve` 같은 주소로 열어 주세요.
