## 숲공부 프로토타입 (`prototype/`)

묘목 한 칸에서 시작해, 공부한 시간과 찾아온 손님으로 레벨을 올리며 끝없이 넓어지는 섬을 키우는 공부 타이머의 맛보기 버전입니다.

### 화면
- 해 질 녘 구름 위에 뜬 섬을 three.js(r128) 3D로 그림. 모바일 힐링 게임 「펭귄의 섬」처럼 깔끔하고 부드러운 화면을 참고해, 평평한 땅을 내려다보고 해 방향에서 **부드러운 그림자**가 짐
- **나무와 동물은 큐브(복셀)로 쌓은 모양**. 나무는 작은 잎 블록 수십 개가 모인 수관이 바람에 흔들리고, 동물은 모서리가 둥근 큐브로 만든 장난감 같은 모양
- 나무: 참나무, 자작나무, 벚나무, 버드나무, 계단식 가문비나무·소나무(설원은 눈 쌓임), 대나무, 야자수, 선인장. 어미나무는 새싹 → 덤불 → 어린나무 → 큰나무(빛나는 열매)
- 끌어서 섬 위를 이동하고, 두 손가락을 비틀거나 오른쪽 버튼(또는 Ctrl·Shift)으로 끌면 회전, 두 손가락이나 휠로 확대. ⟲ ⟳ 45도 돌리기, ⌂ 어미나무로 돌아가기
- 땅을 앞으로 끌어당기면 카메라 가까운 앞쪽이 녹듯이 투명해지며 사라져서 뒤쪽이 보임
- 섬 가장자리는 흙벽이 안 보일 만큼 덩굴이 빽빽하게 늘어짐 (벚나무·꽃밭은 꽃 덩굴, 돌산은 이끼, 설원은 고드름, 사막·바닷가는 쏟아지는 모래). 물이 가장자리에 닿으면 여러 겹 폭포와 물안개
- 메인 화면에는 레벨, 섬, 타이머만 있고 계정(구글 로그인), 손님 도감, 설정(시연 모드, 처음부터), 도움말은 ☰ 메뉴 안에 있음

### 규칙
- 경험치: 공부 1분마다 1, 처음 찾아온 손님마다 10. 레벨에 필요한 경험치는 15, 50, 110, 200, 325… 로 끝없이 늘어남
- 레벨이 오르면 섬이 **마름모 모양으로 한 바퀴씩** 넓어짐 (끝없음, 새 땅 4×(레벨−1)칸)
- **지형은 넓은 구역(약 7×7칸, 경계는 들쭉날쭉) 단위로 하나씩** 저절로 정해짐. 13종: 꽃밭, 초원, 참나무 숲, 자작나무 숲, 벚나무 숲, 침엽수림, 강, 습지, 돌산, **사막, 설원, 대나무숲, 바닷가**. 구역 사이는 높이와 색이 부드럽게 섞임. 옆 구역과 같은 지형은 잘 안 나오고, 아직 못 만난 손님이 사는 지형이 더 잘 나옴
- 구역마다 손님이 **한두 마리** 삶 (구역이 8칸 넘게 열리면 찾아옴). 손님 25종

- 시연 모드: 1초를 1분으로 계산 (메뉴 → 설정)
- 게스트는 이 브라우저(localStorage)에만 저장. **구글로 로그인**하면 클라우드에도 저장돼서 다른 기기에서 이어 할 수 있음 (더 최근 기록을 씀, 공부가 끝난 기록만 올라감). 예전 저장(칸마다 지형)은 레벨·경험치·도감을 그대로 두고 새 방식으로 바뀜
- WebGL이 안 되는 기기에서는 섬 대신 안내 문구가 나오고 타이머와 기록은 그대로 쓸 수 있음

### 구글 로그인 (Firebase)

지금은 소울나이트식 게임(`20260625` 저장소, `feature/roguelike-shooter-pc`)과 같은 Firebase 프로젝트 `dongeon-shooter`를 함께 써요. 나중에 이 게임 전용 프로젝트로 바꾸려면 `prototype/index.html`의 `FIREBASE` 값만 바꾸면 돼요.

저장 위치는 `forest/{uid}` = `{ data: "섬 기록 JSON", t: 마지막 저장 시각 }` 이에요. 소울나이트의 `saves/{uid}`와 섞이지 않게 따로 뒀어요.

Firebase 콘솔에서 처음 한 번:
1. **Realtime Database → 규칙**의 `"rules"` 안에 아래 항목을 추가하고 게시 (기존 `users`, `saves`, `guild…` 규칙은 그대로)
   ```json
   "forest": {
     "$uid": { ".read": "auth != null && auth.uid === $uid", ".write": "auth != null && auth.uid === $uid" }
   },
   ```
2. **Authentication → 설정 → 승인된 도메인**에 게임을 여는 주소가 있는지 확인 (GitHub Pages면 `kimjaeyun091018-spec.github.io`는 이미 들어 있음)

규칙을 추가하기 전에도 게임은 그대로 되고, 계정 칸에 "권한이 없어요"라고만 나와요. 파일을 컴퓨터에서 바로 열면(`file://`) 구글 로그인이 안 되니, GitHub Pages나 `npx serve` 같은 주소로 열어 주세요.
