# 민둥산 창세기

위에서 산 전체를 내려다보며 생태계를 만들어 가는 **신의 시점 실시간 시뮬레이션**.
바위와 마른 흙뿐인 민둥산, 산 아래 강, 강가의 묘목 하나에서 시작해요.
`index.html` 한 파일로 PC·휴대폰 브라우저에서 바로 실행되고, 진행은 브라우저에 자동 저장돼요.

## 신의 도구
| 도구 | 하는 일 |
|---|---|
| 살펴보기 | 땅·나무·동물을 눌러 상태를 봐요 (해발 고도, 수분, 흙 기름짐, 나무 높이·나이·건강, 동물이 하는 일). 확대했을 때 끌면 지도가 움직여요. |
| 비 | 누르고 있는 곳에 비구름을 내려요. |
| 씨앗 | 이끼 · 풀씨 · 들꽃 · 자작나무 · 소나무 · 참나무 · 버드나무. 땅이 맞지 않으면 싹이 안 트고 이유를 알려 줘요. |
| 바위 깨기 | 바위를 부숴 척박한 흙으로 만들어요. |
| 생명 | 새 · 토끼 · 사슴 · 여우 · 비버를 보내요. |
| 베어내기 | 나무를 베어요. 병든 나무는 살릴 수 없지만, 일찍 베면 옆 나무로 번지는 걸 막아요. 벤 자리엔 그루터기가 남아요. |

시간은 멈춤 / 1배 / 4배 / 16배. 휠·두 손가락·＋− 버튼으로 확대. 키보드 1~6 도구, 스페이스 멈춤.
도구는 **신력**을 써요. 살아 있는 생명이 많고 다양할수록 신력이 빨리 차요.

## 저절로 일어나는 일
- **물**: 강에서 스며 나와 퍼지고, 햇볕에 마르고, 비구름이 지나가며 적셔요. 숲과 풀이 많을수록 땅이 덜 마르고 비도 자주 와요.
- **바위 → 흙**: 이끼가 바위에 퍼지며 천천히 바위를 흙으로 바꿔요.
- **풀과 들꽃**: 촉촉하고 기름진 흙을 따라 번지고, 흙을 더 기름지게 해요.
- **나무 4종**: 수분·흙·그늘에 따라 실시간으로 자라고, 다 크면 바람에 씨앗을 날려 숲이 번져요. 늙거나 말라 쓰러지면 통나무가 썩어 거름이 돼요.
  - 자작나무: 척박해도 빨리 자라는 개척자, 일찍 죽음
  - 소나무: 메마르고 높은 곳도 견딤, 겨울에도 푸름
  - 참나무: 기름진 흙이 필요하지만 크고 오래 삶
  - 버드나무: 물가에서만 자람
- **병충해 (시한부)**: 병든 나무는 **낫지 않아요**. 나무마다 정해진 날(자작나무 약 18일 · 버드나무 약 23일 · 소나무 약 28일 · 참나무 약 35일)이 지나면 쓰러져요. 남은 날은 나무 둘레의 빨간 고리로 보여요.
  - 병든 나무는 자라지도, 씨앗을 맺지도 않고 옆 나무로 병을 옮겨요. 같은 나무끼리 빽빽할수록 잘 생기고 잘 번져요.
  - 새가 병든 나무에 앉아 벌레를 쪼면 그동안 번지지 않아요 (고리가 금색). 새가 많을수록 병도 덜 생겨요.
  - 쓰러진 자리엔 **그루터기**가 남아요. 그 흙엔 병이 1년 동안 남아 **같은 나무는 못 자라요**. 다른 나무를 심으면 빛이 드는 자리라 오히려 잘 싹터요.
- **동물**: 토끼는 풀과 새싹을, 사슴은 풀과 어린나무를 먹고, 여우는 토끼를 사냥해요. 새는 나무를 오가며 벌레를 잡고 씨앗을 멀리 옮기고 노래해요. 비버는 물가 나무를 베어 댐을 쌓고, 연못이 생기면 주변 땅이 촉촉해져요. 배고프면 굶어 죽고, 배부르면 새끼를 낳아요.
- **계절**: 봄·여름·가을·겨울이 30일씩 (1배 기준 한 계절 2분). 지도 왼쪽 위 계절 바퀴에 오늘 날짜와 다음 계절까지 남은 날이 보이고, 계절이 바뀌면 화면에 크게 알려 줘요.
  | 계절 | 모습 | 일어나는 일 |
  |---|---|---|
  | 봄 | 새잎 연두빛, 나무에 꽃, 꽃잎이 날림, 들꽃 만발 | 씨앗이 가장 잘 싹틈, 동물이 새끼를 낳음, 병이 적음 |
  | 여름 | 짙은 초록 | 가장 빨리 자람, 땅이 빨리 마름, 병충해가 가장 많음 |
  | 가을 | 단풍, 낙엽이 날림 | 나무가 씨앗을 많이 떨굼, 낙엽이 흙을 두 배로 기름지게 함 |
  | 겨울 | 눈, 잎 진 가지, 언 강 | 성장 멈춤, 병충해 없음, 동물이 배고픔. 이때 뿌린 씨앗은 잠들었다가 봄에 한꺼번에 싹틈 |

## 소리
녹음 파일 없이 브라우저에서 직접 만들어요. 새마다 다른 울음(박새·곤줄박이·딱새·꾀꼬리, 오색딱따구리는 나무를 두드림), 강물 소리, 빗소리.

## 창조 일지
이끼가 바위를 흙으로 · 산자락의 풀밭 · 첫 나무가 다 자람 · 작은 숲 · 첫 새소리 · 먹이사슬 · 비버의 연못 · 꼭대기의 나무 · 새가 번짐을 막음 · 열 가지 생명 · 푸른 산.
균형이 무너질 때(토끼가 풀을 다 먹음, 병이 번짐, 병으로 나무가 쓰러짐, 가뭄, 한 종이 사라짐)도 일지에 남아요.

## 실행
`index.html`을 브라우저로 열면 끝. GitHub Pages에서는 Settings → Pages에서 이 브랜치(`god-ecosystem`)와 root를 고르세요.
