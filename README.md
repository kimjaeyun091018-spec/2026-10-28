# 주사위 × 카드 로그라이크 (가제)

도트 그래픽으로 만드는 턴제 로그라이크. **카드가 '무엇을 할지', 주사위가 '얼마나 잘할지'**를 정한다.

> 이 브랜치(`dice-card-roguelike`)에는 이 게임만 둔다. 숲공부 프로토타입은 `main` 브랜치에 있다.

## 핵심 시스템

- **주사위 = 에너지**: 턴 시작에 주사위 3개를 굴리고, 나온 눈을 카드에 넣어 발동한다.
- **카드 = 행동**: 카드마다 받을 수 있는 눈의 조건이 다르다 (예: "6만", "짝수만", "합이 7 이상", "같은 눈 2개").
- **카드는 손패로 뽑는다**: 덱에서 매 턴 카드를 뽑기 때문에 "이번 굴림"과 "이번 손패"를 함께 맞춰야 한다.
- **리롤**: 턴당 1회.

## 성장 요소

- 전투 승리 후 카드 3장 중 1장 선택
- 주사위 면 강화 (1→6, 불꽃 면, 두 배 면 등)
- 유물: 패시브 효과 (예: 홀수가 나오면 체력 1 회복)
- 갈림길 맵: 전투 / 상점 / 휴식 / 보스

## 첫 버전 범위

1. 주사위 3개, 카드 10종, 적 5종, 보스 1종
2. 일직선 맵 5층
3. 승리 시 카드 보상만

## 그래픽

- 16×16 또는 32×32 도트, 캔버스 코드로 그림
- 화면 구성: 적 + 카드 손패 + 주사위 트레이

## 비슷한 게임 (참고용)

| 게임 | 방식 | 이 게임과 다른 점 |
|---|---|---|
| Dicey Dungeons (2019) | 주사위를 장비 칸에 넣어 발동 | 장비는 고정 배치, 덱에서 뽑지 않음 |
| Slice & Dice (2024) | 영웅 5명이 각자 주사위 | 카드 없음, 파티 주사위 |
| Die in the Dungeon (2026 정식) | 주사위가 곧 덱, 판에 배치 | 카드 없음 |
| DICEOMANCER (2024) | 카드 덱빌더 + D20 판정·숫자 변경 | 주사위가 보조 역할 |
| Dice A Million (2026) | 주사위 가방으로 점수 쌓기 | 전투 없음, 카드 없음 |
