# 주사위 던전 (주사위 × 카드 로그라이크)

도트 그래픽으로 만드는 턴제 로그라이크. 요트 다이스의 주사위 족보와 포커의 카드 족보를 한 전투에 섞었다.

> 이 브랜치(`dice-card-roguelike`)에는 이 게임만 둔다. 숲공부 프로토타입은 `main` 브랜치에 있다.

## 핵심 시스템 (필드 동료 + 요트 + 포커)

- 손패의 **동료 카드**를 필드 5칸(벤치 없음)에 낸다. 동료는 쓰러질 때까지 필드에 남는다.
- 매 턴 **주사위 5개**를 굴리고, 요트처럼 고정하며 **다시 굴림 2번**. 확정하면 주사위를 동료에게 넣는다.
- 동료의 **레벨 = 발동 숫자**. 레벨 1~6은 그 수 이상인 눈 1개, 레벨 7~12는 주사위 2개 합이 그 수 이상이면 기술 발동 (동료마다 턴에 1번).
- 에너지를 쌓지 않는다. 그 턴의 주사위 눈으로만 행동한다.
- **아이템**: 턴에 몇 장이든 / **서포트**: 턴에 1장. 둘 다 주사위 없이 사용.
- 기사(플레이어 캐릭터) 없이 **필드의 동료와 적만 대치**한다. 적은 동료 하나를 노리고(미리 표시), 공격받을 때 필드에 동료가 하나도 없으면 패배.
- 방어는 우리 편 전체를 지키는 방패로, 턴이 시작되면 사라진다.

### 카드

| 종류 | 카드 |
|---|---|
| 불 동료 | 불도마뱀 LV2 피해 6 · 불곰 LV4 피해 11 · 화염룡 LV9 피해 24 |
| 물 동료 | 물방울 LV1 방어 5 · 바위거북 LV3 방어 10 · 해마 LV5 회복 12 |
| 풀 동료 | 새싹 LV2 독 3 · 덩굴뱀 LV4 독 6 · 고목 LV8 모두 회복 7 |
| 번개 동료 | 번개새 LV3 관통 6 · 뇌수 LV6 관통 15 · 천둥거인 LV11 관통 30 |
| 아이템 | 회복약 · 숫돌(눈 +1) · 행운 동전(다시 굴림 +1) · 나무 방패(방어 +8) |
| 서포트 | 견습 마법사(2장 뽑기) · 대장장이(주사위 +1) · 치유사(모두 회복 10) |

### 주사위 족보 (요트)

| 족보 | 조건 | 효과 |
|---|---|---|
| 요트 | 5개 같은 눈 | 모든 피해 2배 |
| 포카드 | 같은 눈 4개 | 피해 +10 |
| 풀하우스 | 3개 + 2개 | 방어 +10 |
| 라지 스트레이트 | 5개 연속 | 피해 +8 |
| 스몰 스트레이트 | 4개 연속 | 피해 +4 |

### 필드 족보 (포커, 필드의 동료끼리: 레벨 = 숫자, 속성 = 모양)

| 족보 | 조건 | 효과 |
|---|---|---|
| 원페어 / 투페어 | 같은 레벨 2마리 | 피해 +3 / +6 |
| 트리플 | 같은 레벨 3마리 | 피해 +8 |
| 스트레이트 | 레벨 3개 연속 | 매 턴 다시 굴림 +1 |
| 플러시 | 같은 속성 3마리 | 불 피해 +6 · 물 방어 +6 · 풀 독 +4 · 번개 관통 +5 |

## 진행

- 지하 5층 (슬라임·박쥐 → 독버섯 → 해골 병사 → 돌 골렘 → 주사위 마왕)
- 층을 깰 때마다 카드 3장 중 1장 선택(넘어가기 가능), 필드는 새로 시작
- 첫 손패 5장에는 동료가 2장 이상 들어오고, 이후 매 턴 2장씩 뽑음 (손패 최대 8장)

## 앞으로 넣을 것

- 주사위 면 강화 (1→6, 불꽃 면 등), 유물(패시브 효과)
- 갈림길 맵: 전투 / 상점 / 휴식 / 보스

## 그래픽

- 16×16 도트, 캔버스 코드로 그림 (이미지 파일 없음)
