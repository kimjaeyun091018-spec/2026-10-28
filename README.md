# 종이 접는 용사 (가제)

**종이에 그린 그림**이 주인공이고, 적과 도구는 종이, 세계는 **신비로운 도트(픽셀아트) 숲**인 2D 액션 게임. 모험하며 **종이접기 도안**을 얻고, 그 도안의 점선을 따라 직접 종이를 접어 무기·도구를 만든다. **점선에 얼마나 정확히 맞춰 접었는지에 따라 도구의 성능이 달라진다.**

> 이 브랜치(`orgami`)에는 이 게임만 둔다. 숲공부 프로토타입은 `main`, 식물 액션(「뿌리 아래로」)은 `plant-world-action`에 있다.

## 출발점

`plant-world-action`의 "3D 배경 + 2D 캐릭터"에서 영감을 받음. 2D로 간다면 캐릭터가 아예 종이라면 어떨까 → 납작한 것이 자연스러운 세계, 종이를 겹친 디오라마 같은 배경.

그 뒤 방향: 주인공은 종이에 그린 그림처럼. 배경과 맵은 사실적인 사진풍(RealVisXL)을 한 번 해 봤다가, `plant-world-action`처럼 **SDXL + 픽셀아트 LoRA 도트**로 바꿈 (환상적이고 신비로운 분위기는 LoRA로 충분).

## 핵심 규칙

1. 도안을 얻는다 (세계 곳곳의 책상에 놓여 있음)
2. 종이 위에 점선이 보이고, 플레이어가 종이를 잡아 끌어서 접는다
3. **한 번 접는 데 시간 제한(5초 / 3초)**. 시간이 다 되면 잡고 있던 그대로 접히고, 잡고 있지 않았으면 손이 미끄러져 비뚤게 접힘(그 단계 0%)
4. 접는 선이 점선과 얼마나 겹치는지로 단계마다 정확도가 매겨지고, 평균으로 도구 등급(S~D)과 성능이 정해진다
5. 비뚤게 접으면 다음 점선도 비뚤어진 종이를 따라 옮겨 간다 (실제 종이접기처럼 오차가 쌓임)
6. 만든 도구는 게임 안에서 **실제로 접은 모양 그대로** 보인다 — 비뚤게 접은 칼은 비뚤어 보임

## 첫 프로토타입 (`index.html`)

브라우저로 `index.html`을 열면 바로 플레이 (설치·빌드 없음). 마우스 + 키보드.

### 접기 화면
- 커팅 매트 위 정사각형 종이. 실제 종이접기처럼 색면을 아래로 두고 시작해서, 접어 넘긴 면에 색이 보임
- **반짝이는 점을 잡고 화살표 끝으로 끌어 놓기**: 잡은 점이 놓은 곳에 오도록 접힘 (접는 선 = 두 점의 수직이등분선). 끄는 동안 접힌 결과와 내 접는 선, 정확도가 바로 보임
- 정확도: 점선 양 끝 두 점에서 내 접는 선까지의 평균 거리(종이 한 변 = 200). 0이면 100%, 14 이상이면 0%. 34보다 멀거나 반대쪽을 잡으면 접히지 않음
- 단계 정확도 평균 → 등급 S(93%+) · A(82%+) · B(68%+) · C(50%+) · D
- **시간 제한**: 매트 아래 막대가 남은 시간(새 단계가 나타난 뒤 0.4초 여유). 1.5초 아래면 빨갛게 깜빡임. 매트 오른쪽 아래 버튼으로 5초 ↔ 3초 (이 브라우저에 기억)
- R: 새 종이로 처음부터, Esc: 나중에. 이미 만든 도구도 책상에서 E로 다시 접어 바꿀 수 있음

### 도안 4종

| 도안 | 단계 | 역할 | 정확도가 바꾸는 것 |
|---|---|---|---|
| 종이 칼 | 5 | 근접 베기 (J·왼쪽 클릭) | 공격력 1~3, 사거리 22~52px |
| 종이비행기 | 5 | 공중에서 점프 누르고 있으면 활공 | 낙하 속도 150→30, 이동 ×1.0~1.35 |
| 종이 표창 | 4 | 마우스 쪽으로 던지기 | 위력, 사거리 190~520px, 흔들림 ±14°→0° |
| 종이 방패 | 4 | K·오른쪽 클릭 누르고 있으면 앞쪽 막기 | 막기 횟수 2~8번 (다 쓰면 찢어짐 → 다시 접기) |

### 스테이지 (한 판, 약 4000px)
- 칼 책상 → 구김이(구겨진 종이 뭉치) → 비행기 책상 → **물웅덩이 300px** (활공 없이는 못 건넘. 끝에서 뛰면 비행기 정확도 약 45% 이상이어야 건넘)
- 표창 책상 → 물웅덩이(220px) 건너편 **병풍 문** 앞면 높은 곳의 과녁을 표창으로 맞히면, 병풍이 쓰러져 다리가 됨 (웅덩이 건너에서 던져야 해서 표창 정확도 약 40% 아래면 사거리가 모자람)
- 방패 책상 → **잉크병** 두 개가 잉크를 3연발로 쏨 → 황금 종이학에 닿으면 클리어 (도구별 등급 결과 화면)
- 체력 5 (종이 하트). 물에 빠지면 -1, 책상이 체크포인트

### 그림
- **주인공 = 종이에 그린 그림을 오려낸 것** (캔버스 코드): 흰 종이 여백과 그림자, 연필 선(두 번 그은 듯 어긋남), 크레파스 칠(비치는 칠 + 빗금). 손그림 애니메이션처럼 선이 1초에 7번 떨림. 팔·다리·목도리가 걷기·점프·활공·베기·막기에 맞춰 움직이고, 도구는 손에 쥠. 돌아설 때 종이처럼 얇아지며 뒷면(반대로 비친 그림)이 보임
- **세계 = 도트(픽셀아트)** (`assets/pixel/`, Kaggle 무료 GPU + SDXL base + 픽셀아트 LoRA `nerijs/pixel-art-xl`, `tools/pixel-gen/gen_kaggle.py`·`push.py`)
  - 받은 그림은 `python tools/pixel-gen/to_pixel.py <받은 폴더>`로 도트 격자에 맞춰 줄이고 색 수를 제한함 (배경 224×128·48색, 질감 112×112·24색, 질감은 가장자리를 섞어 이음새 없이 반복)
  - `bg-forest.png`(빛 반딧불이 떠도는 안개 숲) → 카메라가 1300px를 넘으면 `bg-river.png`(냇가)로 서서히 바뀜. 흐리게 늘이지 않고 또렷하게 확대
  - 땅: `soil.png`(흙) + `moss.png`(풀 띠) + 코드로 찍은 풀 끝·작은 꽃. 발판: `wood.png`(판자). 물웅덩이도 도트(칸 단위로 출렁이는 수면, 반짝이는 점). 도트 한 칸 = 화면 3px
  - 접기 화면의 책상도 `wood.png`
  - `assets/pixel/gen/`: 생성한 원본 전부(숲 4, 냇가 4, 질감 6)와 프롬프트
  - 도트 그림을 못 불러오면 예전 종이 디오라마 배경(`assets/bg-forest.jpg`)으로 그림
  - 해 봤다가 안 쓰기로 한 사진풍 생성 도구는 `tools/real-gen/`에 기록으로 남김 (프롬프트는 파일 안)
- 적(구김이)·도구·병풍은 종이, 잉크병은 유리병 느낌
- `assets/concept/`: 처음 종이 공예 화풍 시안 (숲 4, 마을 4, 종이 주인공 4)과 프롬프트
