## 숲공부 프로토타입 (`prototype/`)

묘목 한 칸에서 시작해, 공부한 시간과 찾아온 손님으로 레벨을 올리며 섬을 넓혀가는 공부 타이머의 맛보기 버전입니다.

- 해 질 녘 구름 위에 뜬 섬을 45도 각도에서 내려다보는 화면. 섬 가장자리에는 빛나는 덩굴이 늘어지고, 아래로는 바위 뿌리와 안개가 깔림. 섬 끝에 닿은 강은 폭포가 되어 떨어짐
- 나무와 땅은 캔버스로 그리고, **동물은 three.js(r128)로 만든 3D 모델**. 공·막대·뿔 같은 단순한 도형을 이어 붙이고 두 단계 명암(툰 셰이딩)으로 칠해 장난감 같은 느낌. 동물은 가는 방향으로 몸을 돌리고, 걷기·뛰기·날기·헤엄 동작이 있음 (이미지 파일 없음)
  - 비버는 물 위로 나온 부분만 보이고, 피라미는 물속에선 흐리게 보임
  - three.js를 못 불러오거나 WebGL이 안 되면 예전 2D 그림(「민둥산의 묘목」 스타일)으로 그림
- 시작은 어미나무 묘목 1칸. 공부할수록 새싹 → 덤불 → 어린나무 → 큰나무로 자람
- 손님(실제 생물)이 처음 찾아올 때마다 경험치 +10, 공부 1분마다 +1. 레벨이 오르면 십자 모양으로 땅이 한 바퀴씩 열림 (Lv 5까지, 최대 41칸)
- **지형은 저절로 생김**: 땅이 열리면 초원, 꽃밭, 참나무 숲, 자작나무 숲, 벚나무 숲, 침엽수림, 강, 습지, 돌산 중에서 무작위로 정해짐. 고르거나 살 필요 없이 공부만 하면 됨
  - 옆 칸과 같은 지형이 잘 나와서 숲·돌산이 덩어리로 생김
  - 아직 못 온 손님에게 필요한 지형이 더 잘 나옴. 강이 생기면 옆에 숲이 붙어 비버도 올 수 있음 (무작위 섬 200개를 Lv 5까지 키워 보니 모두 18종이 다 찾아옴)
  - 지형을 누르면 이름과 찾아오는 손님이 나옴
- 손님 18종: 무당벌레, 참새, 배추흰나비, 꿀벌, 멧토끼, 다람쥐, 박새, 오색딱따구리, 동박새, 여우, 노루, 피라미, 비버, 참개구리, 반딧불이, 왜가리, 산양, 검독수리. 지형 조합으로 찾아옴 (예: 참나무·자작나무 숲 옆에 강이 있으면 비버)
- 공부 중 화면을 벗어나면 그 세션은 없던 일이 됨 (경험치·손님·땅 모두 세션 시작 전으로)
- 시연 모드: 1초를 1분으로 계산
- 게스트는 이 브라우저(localStorage)에만 저장. **구글로 로그인**하면 클라우드에도 저장돼서 다른 기기에서 이어 할 수 있음
  - 로그인하면 기기와 클라우드 중 **더 최근 기록**을 씀
  - 공부가 끝난 기록만 올라감 (공부 중엔 안 올리고, 화면을 벗어나 되돌아간 세션도 안 올라감)
  - 공부하는 동안엔 로그인 버튼이 꺼져 있음

### 구글 로그인 (Firebase)

지금은 소울나이트식 게임(`20260625` 저장소, `feature/roguelike-shooter-pc`)과 같은 Firebase 프로젝트 `dongeon-shooter`를 함께 써요. 나중에 이 게임 전용 프로젝트로 바꾸려면 `prototype/index.html`의 `FIREBASE` 값만 바꾸면 돼요.

저장 위치는 `forest/{uid}` = `{ data: "섬 기록 JSON", t: 마지막 저장 시각 }` 이에요. 소울나이트의 `saves/{uid}`와 섞이지 않게 따로 뒀어요.

Firebase 콘솔에서 처음 한 번:
1. **Realtime Database → 규칙**의 `"rules"` 안에 아래 항목을 추가하고 게시 (기존 `users`, `saves`, `guild…` 규칙은 그대로)
   ```json
   "forest": {
     "$uid": { ".read": "auth != null && auth.uid === $uid", ".write": "auth != null && auth.uid === $uid" }
   },
   ```
2. **Authentication → 설정 → 승인된 도메인**에 게임을 여는 주소가 있는지 확인 (GitHub Pages면 `kimjaeyun091018-spec.github.io`는 이미 들어 있음)

규칙을 추가하기 전에도 게임은 그대로 되고, 계정 칸에 "권한이 없어요"라고만 나와요. 파일을 컴퓨터에서 바로 열면(`file://`) 구글 로그인이 안 되니, GitHub Pages나 `npx serve` 같은 주소로 열어 주세요.

### 실행

`prototype/index.html`을 브라우저로 열면 됩니다. 별도 빌드나 설치는 없습니다.
